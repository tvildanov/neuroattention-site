## 6. Приоритет №2 — Новый инструмент **Скетч** (Sketch / Boceto)

Ник запросил новый инструмент рисования, встроенный в существующий 3D-Атлас (не отдельный движок). **Идёт после bug backlog.** Полное ТЗ ниже.

### 6.1 Название
- Русский: **Скетч** (или дубль «Скетч / Набросок»)
- English: **Sketch**
- Español: **Boceto**

Простое, минималистичное, не «творческое».

### 6.2 Расположение
- Отдельная вкладка в **Инструменты → Скетч**
- Плюс **универсальная плавающая кнопка** на всём сайте — полупрозрачная, при hover подсвечивается, делает **скриншот любой точки сайта** (даже текста, интерфейса, любого ЛК) и открывает Sketch поверх

### 6.3 Кнопка «создать копию» — где появляется
- **Атлас**: рядом с панелью search/hide/isolate
- **Библиотека**: правый верхний угол каждой картинки статьи (при hover)
- **NeuroMap**: 2D + 3D (там уже есть 3D-режим — потом унифицируем движки, см. §6.10)
- **Путь**: только 2D (нет 3D)
- **Универсальная плавающая** — везде на сайте

### 6.4 Режимы копии
При нажатии кнопки «создать копию» — выбор: **создать 3D копию** или **создать 2D копию**.
- **3D копия из Атласа** — берём выбранный орган, дублируем меш в новое окно Sketch
- **2D копия из 3D** — скриншот текущего вида 3D-модели → 2D картинка
- **2D копия из 2D** — картинка из Библиотеки/скриншот дневника → 2D
- **3D копия из 2D** — 2D картинка становится плоскостью (плакатом) в 3D-пространстве, вокруг можно ходить и рисовать спереди/сзади

### 6.5 Слои (максимум 5)
1. **Фон** — цвет + прозрачность настраиваемые
2. **Изображение/модель** — не рисуется, НО с ним можно работать: выделять части, менять цвет отдельных участков, менять прозрачность отдельных участков, стирать ручкой-ластиком, весь слой имеет ползунок прозрачности и переключатель видимости
3. **Рисующий слой #1** — свой ползунок прозрачности + переключатель видимости
4. **Рисующий слой #2** — свой ползунок прозрачности + переключатель видимости
5. **Рисующий слой #3** — свой ползунок прозрачности + переключатель видимости

Слои можно переставлять местами (изменять z-порядок).

### 6.6 Кисти
Стартовый набор:
- Ручка (тонкая линия)
- Фломастер (толстая непрозрачная)
- Маркер (толстая полупрозрачная)
- Карандаш (текстурная)
- Ластик

Настройки каждой: **размер + цвет + прозрачность**.

### 6.7 Undo/Redo
- 50 шагов назад / 50 вперёд
- Кнопки стрелочками

### 6.8 Шаблоны
- **Мои шаблоны** — сохраняются в БД под user_id, отображаются во вкладке инструмента
- **Общие шаблоны** — папка с шаблонами, опубликованными суперадмином (см. §6.9)
- Готовых заготовок предзагружать НЕ надо (Ник не хочет мешков)
- Сохранённый шаблон можно в любой момент открыть → продолжить редактирование → откатиться назад по истории

### 6.9 Superadmin publish
Механизм: если суперадмин сохранил шаблон → у него в UI появляется кнопка «сделать общедоступным». По клику — шаблон копируется в «Общие шаблоны» и виден всем пользователям с доступом к Sketch.

### 6.10 Расшаривание
Возможности расшарить шаблон:
- **Юзер → юзеру** через DOMunity чат (получатель может сохранить себе или сразу открыть)
- **Специалист ↔ клиент** через специальный чат-тред (когда мы его сделаем)
- **Прикрепить к курсу** — суперадмин может привязать шаблон к курсу, студенты видят
- **Прикрепить к стриму** — когда coach ведёт стрим для группы, он может показать шаблон и **крутить его в реальном времени** (люди видят как вращается)

### 6.11 Экспорт
- **PNG** для 2D
- **PNG-скриншот** или **.glb** для 3D
- Скачивание на устройство

### 6.12 Архитектурное решение — КРИТИЧНО
- **НЕ строить новый 3D-движок.** Использовать существующий движок из Атласа.
- **Вынести из Атласа общее 3D-ядро в отдельный модуль** (`assets/js/three-core.js` или подобное): renderer, камера, свет, слои, tint API, экспорт. Атлас переходит на этот модуль без ломки.
- Скетч строится на том же ядре.
- **NeuroMap 3D — НЕ ТРОГАТЬ сейчас.** Он работает качественно, у него свой Three.js. Отдельная задача **после** Скетча: перенести NeuroMap 3D на то же ядро с feature flag и side-by-side сравнением, чтобы не потерять качество.
- Итого: один движок для рендера, три разных сцены (Атлас: человек / Скетч: canvas+слои / NeuroMap: граф). Они не конфликтуют.

### 6.13 Что не делать в MVP
- Ник согласился на **одну фазу** для Скетча (не разбивать), кроме NeuroMap-миграции на общее ядро — это Phase 2.
