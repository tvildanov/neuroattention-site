# DOM Typology — переносимая рабочая спецификация

Версия 0.4, 17 ноября 2026. Владелец замысла: Никита.

Цель: вместе достроить систему типирования до удобного инструмента участника DOM Institute и подготовить воспроизводимые инструкции для агента или нескольких агентов на разных хостах. Это рабочая методика и основа будущего skill; добавлен отдельный исполнимый черновик анкеты. Установленного skill, валидированного расчёта и запущенной мультиагентной системы пока нет.

## Текущая точка продолжения

Сначала прочитать [CONTINUE.md](CONTINUE.md): новые требования Никиты, порядок совместной работы и актуальное состояние анкеты. После каждого содержательного ответа обновлять эту точку и сохранять изменения в GitHub. Не требовать от основателя восстанавливать весь архив.

## С чего начать на новом хосте

1. Прочитать [полный handoff, полученный текстом из сообщения](sources/2026-08-26-handoff-chat-transcription.md), [его разбор](HANDOFF-REVIEW.md) и [контракт будущего агента](AGENT-CONTRACT.md).
2. Проверить [решения и нерешённые вопросы](DECISIONS.md).
3. Использовать [реестр источников](SOURCES.md); не считать метаданные прочитанным документом.
4. Для методики Homo Conscius прочитать [заметки](sources/2026-11-16-homo-conscius-notes.md) и [новые уточнения Никиты](sources/2026-11-16-user-requirements.md).
5. Для состояния реализации прочитать [аудит](../DOM-ACCOUNT-TYPOLOGY-AUDIT-20261116.md) и [продолжение](../DOM-ACCOUNT-TYPOLOGY-HANDOFF.md). Перед изменениями проверить свежий код: аудит фиксирует определённый SHA.
6. Для связей с другими системами прочитать [контракт интеграции](INTEGRATION.md).

Markdown и JSON читаются без ChatGPT, Library, Монады или конкретной модели. Копирование этой папки переносит текущие документы, но не полные байты внешних исходников: их покрытие явно указано в реестре. Пока новые исходники не собраны полностью, экспорт не является полным архивом метода.

## Реализованный черновик первой анкеты

[Все 13 характеристик и 40 вопросов](BASELINE-13-REVIEW.md). [Версионированные данные](../../data/typology/baseline-13.draft.json), [страница](../../typology-baseline.html), [движок](../../assets/js/dom-typology-core.js).

Реализованы ответы, пропуски, восстановление и экспорт. Это сбор самоотчётных данных; баллы, уверенность, 12 профилей, WMC и XP пока не рассчитываются. Семь проверок логики прошли; браузерная проверка остаётся открытой. Код находится в рабочей ветке, в личный кабинет не встроен и не развёрнут.

Следующий шаг — проверить формулировки блоками и определить допустимые правила интерпретации, затем объединить самоотчёт с поведенческими данными. Описательные исторические уровни не равны ключам начисления баллов. Отдельно сохраняются матрица-кандидат 13×13 и методическая незавершённость Space Awareness.

Публичная папка содержит документацию проекта. Не сохранять здесь результаты, дневники, закрытые профили, токены или исходные наблюдения участников. Открытость документации не задаёт открытость профилей.
