## Главный вывод

Сохранить данные, библиотеку материалов, модели участия, ресурсы анатомии и пригодные API. Постепенно заменить оболочку кабинета, контракт подтверждённой записи и представления карты/пути. Оснований удалять систему целиком аудит не дал. Текущая реализация требует больше, чем косметической смены темы.

Первая проверяемая единица продукта: человек записывает наблюдение, видит подтверждённый результат, открывает исходник из истории и карты, выбирает уместное действие и сравнивает состояния до/после. Пока этот цикл не надёжен, расширение числа экранов и эффектов увеличивает сложность.
