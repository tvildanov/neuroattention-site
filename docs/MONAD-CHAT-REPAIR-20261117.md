## Changes
- Empty successful polls are authoritative; the raw reader is used only when the primary poll fails.
- Site-origin human echoes are filtered, and local human seed IDs suppress matching echoes without a time window.
- Imports are batched in a transaction with a per-chat advisory lock, preventing overlapping polls from inserting multiple copies.
- Identifiable stored echoes are omitted from the response without deleting history. Human voice transcripts and technical vocabulary are retained.
- Enter sends and polls cannot overlap; stale responses cannot overwrite another selected chat. Long chats display the newest 500 entries chronologically.
- The cabinet exposes a sanitized quota code and localized RU/EN/ES notices for the selected LK provider, rather than presenting configuration alone as evidence that replies are working.
- Monad asset v24 and service-worker v97 are published. Persona routing, permissions and parallel typology work are unchanged. No schema migration is needed.
