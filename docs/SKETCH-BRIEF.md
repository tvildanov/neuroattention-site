## Что нужно на самом деле (по запросу Ника)
Инструмент **Скетч** — это не paint/рисовалка на пустом холсте.

Нужно:
1. **Слои** (как в графическом редакторе): включать/выключать, прозрачность, порядок.
2. **Рисование поверх 3D-модели** — аннотации на теле / анатомической модели (тот же мир, что атлас / Internal Field), а не на пустом прямоугольнике.
3. Сохранение скетча, привязанного к модели/ракурсу/слоям.
4. Смысл: быстро отметить ощущение, зону, схему воздействия поверх реального тела в 3D.

Исходный подробный handoff-файл Ника в репозитории **не найден** (`nick-handoff-brief-…` был только в чате).  
**Ник — перезалей исходный файл**, чтобы собрать Скетч один-в-один по спеке.

## Что сейчас в коде (временно)
- Tools → **Скетч** показывает пояснение + **временную рисовалку** (pen/eraser/save в `user_sketches`).
- Это **не** продукт «Скетч». Рисовалку можно оставить как черновик или убрать после появления настоящего инструмента.

## План реализации (после брифа)
1. Взять 3D viewer атласа / body model как базу сцены.
2. Overlay-canvas / texture paint по UV или screen-space projection на меш.
3. Панель слоёв (draw / reference / notes).
4. Save: scene camera + layers JSON (+ optional bake PNG).
5. Доступ: Tools → Скетч (или из атласа — уточнить в брифе).

## Не делать снова
- Не выдавать пустой 2D canvas за «Скетч».
- Не плодить отдельный UX pan/zoom, если можно переиспользовать уже существующие механики сайта.
