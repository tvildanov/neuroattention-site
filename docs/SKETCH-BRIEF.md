## Черновик MVP (если ответишь «да, так»)
- Canvas + pen / eraser / color / undo  
- Save PNG + JSON strokes в API (`user_sketches`)  
- Open last sketch  
- Без коллаборации, без слоёв, без AI

## Не в MVP
- 3D, XR, совместное рисование, экспорт в печать, сложные кисти
