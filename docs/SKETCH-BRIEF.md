# Sketch / Скетч / Boceto — product brief

**Источник ТЗ:** `docs/nick-handoff-brief-2026-07-12.md` §6 (Ник, 2026-07-12).  
**Статус:** ядро в проде. 3D = живой BodyAtlas под слоями (не скрин): вращение как в Атласе, рисунок поверх. Шаринг / live-stream / `.glb` — после.  
**Обновлено:** 2026-08-18

## Зачем
Рисовать **поверх** существующего 3D-Атласа (и поверх скринов/картинок сайта): слои, кисти, шаблоны. Не отдельный Photoshop и не новый 3D-движок.

## Где
1. Tools → **Скетч**
2. **Плавающая кнопка** на всём ЛК — скриншот любой точки → открыть Скетч
3. Кнопки «создать копию» в Атласе, Библиотеке, NeuroMap (2D+3D), Пути (только 2D)

## Режимы копии
- **3D из Атласа** — выбранный орган/сцена → новое окно Sketch  
- **2D из 3D** — скрин текущего вида  
- **2D из 2D** — картинка Библиотеки / скрин дневника  
- **3D из 2D** — картинка как плоскость в 3D, рисовать спереди/сзади  

## Слои (макс. 5)
1. Фон (цвет + прозрачность)  
2. Изображение/модель — не «рисуется», но: выделять, tint, прозрачность участков, ластик по слою, видимость  
3–5. Три рисующих слоя (прозрачность + видимость)  
Z-порядок меняется.

## Кисти
Ручка, фломастер, маркер, карандаш, ластик — размер / цвет / прозрачность.  
Undo/Redo: 50 шагов.

## Шаблоны
Мои (в профиле) + Общие (суперадмин «опубликовать»). Без предзагруженных пачек.

## Шаринг (после MVP-ядра)
Юзер↔юзер (DOMunity), специалист↔клиент, привязка к курсу, показ на стриме с live-вращением.

## Экспорт
PNG (2D); PNG-скрин или `.glb` (3D) — PNG готов, `.glb` в backlog.

## Архитектура — критично
- **Не** строить новый Three.js движок.  
- Использовать **BodyAtlas** (`assets/js/body-atlas.js` + `screenshot()`).  
- NeuroMap 3D **не трогать** сейчас (Phase 2 после Скетча).  
- Один рендер-движок, разные сцены.
