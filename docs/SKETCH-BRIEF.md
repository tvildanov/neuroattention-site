# Sketch tool — brief

**Открыть тут (кликабельно):** https://github.com/tvildanov/neuroattention-site/blob/main/docs/SKETCH-BRIEF.md

**Дата:** 2026-08-08

## Зачем
Быстрый визуальный набросок в ЛК — не Photoshop.

## Дефолты (Ник в переезде, ответов на вопросы не было — стартовали так)
1. **Где:** Tools → подвкладка **Скетч** (`?tool=sketch`)
2. **Что:** свободная линия, ластик, цвета, толщина, undo
3. **Куда:** профиль API `user_sketches` (сохранить / открыть / удалить)
4. **Для кого:** любой залогиненный пользователь
5. **Мобильный:** touch включён в MVP

Если хочешь иначе — напиши, перенесём (отдельная вкладка / только суперадмин / в NeuroMap).

## MVP сделано
- Canvas + pen / eraser / color / undo / clear  
- Save strokes (+ PNG preview если не огромный)  
- Список сохранённых → открыть / удалить  

## Не в MVP
- 3D, XR, совместное рисование, слои, AI, привязка к телу
